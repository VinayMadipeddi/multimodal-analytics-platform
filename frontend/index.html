Enabling External Cloud LLM:

To enable cloud LLMs (OpenAI, Gemini, Anthropic), set the respective environment variable in your .env file:

OPENAI_API_KEY="your-api-key"

When no key is configured, the platform safely uses verified deterministic statistical calculations.
